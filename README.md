## Mini Trello — Frontend

Frontend application for a simple Trello-like board, built with Vite, React, TypeScript, Tailwind CSS, and shadcn/ui.

 - Node.js version: 23

### 1 Clone the repository:

```bash
    git clone https://github.com/M1r0H/mini_trello_client.git
    cd mini_trello_client
```

### 2 Install dependencies:

```bash
    npm install
```

### 3 Copy environment variables:

```bash
    cp .env.example .env
```

### 4 Run the application:

```bash
    npm run dev
```
